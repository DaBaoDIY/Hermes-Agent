# Hermes Agent 客户使用说明

本文档面向通过 AWS Marketplace 部署 Hermes Agent 的客户或测试人员。

---

## 1. 部署

1. 在 AWS Marketplace 订阅 Hermes Agent。
2. 选择 CloudFormation deployment 交付方式。
3. 填写参数：

| 参数 | 说明 |
|:---|:---|
| `AmiId` | Marketplace 自动填充，客户不要修改 |
| `ProductCode` | Marketplace Product Code，PRM 使用；如果控制台自动填充则保留 |
| `InstanceType` | 推荐 `t3.small` 起步 |
| `AvailabilityZone` | 选择部署可用区 |
| `AllowedWebCidr` | 允许访问 Web UI 的 CIDR，生产环境不要使用 `0.0.0.0/0` |
| `AllowedSshCidr` | 可留空，优先使用 Systems Manager |
| `KeyName` | 可选 EC2 Key Pair |
| `BedrockModelId` | 默认 `us.amazon.nova-lite-v1:0` |
| `SystemPrompt` | 默认系统提示词 |

4. 勾选 IAM capability。
5. 创建 Stack。
6. 等待 Stack 进入 `CREATE_COMPLETE`。

---

## 2. 获取 Web UI 地址

CloudFormation 输出：

```text
WebUrl
```

浏览器打开：

```text
http://<EC2_PUBLIC_IP>:8080
```

---

## 3. 获取 setup token

CloudFormation 输出：

```text
SetupTokenCommand
```

执行类似命令：

```bash
aws ssm send-command \
  --region <REGION> \
  --instance-ids <INSTANCE_ID> \
  --document-name AWS-RunShellScript \
  --parameters commands='sudo cat /etc/hermes-agent/setup-token'
```

在 Systems Manager Run Command 结果中查看 token。

也可通过 Session Manager 登录实例后执行：

```bash
sudo hermes-agent-ctl token
```

---

## 4. 初始化控制台

1. 打开 `WebUrl`。
2. 输入 setup token。
3. 进入 Hermes Agent 控制台。

---

## 5. 配置 Amazon Bedrock

1. 打开 `运行配置`。
2. 设置 AWS Region。
3. 设置 Bedrock model ID 或 inference profile ID。
4. 保存配置。
5. 点击 `测试模型`。

注意：

- 需要在 Amazon Bedrock 控制台中开通目标模型访问权限。
- EC2 IAM Role 已包含 Bedrock 调用权限。
- Region 必须与模型开通 Region 匹配。

---

## 6. 对话使用

- 在聊天框输入内容。
- 按 `Enter` 发送。
- 按 `Shift + Enter` 换行。

---

## 7. 常用运维命令

```bash
sudo hermes-agent-ctl token
sudo hermes-agent-ctl status
sudo hermes-agent-ctl logs
sudo hermes-agent-ctl restart
```

systemd：

```bash
sudo systemctl status hermes-agent
sudo systemctl restart hermes-agent
sudo journalctl -u hermes-agent -f
```

配置文件：

```text
/etc/hermes-agent/config.json
```

setup token：

```text
/etc/hermes-agent/setup-token
```

---

## 8. 安全建议

- 将 `AllowedWebCidr` 限制为办公网、VPN 或堡垒机 CIDR。
- 不建议公网开放 SSH。
- 使用 Systems Manager Session Manager 运维。
- 不要把 setup token 发送给支持人员。
- 不要把 AWS AK/SK 填入应用。
- 外部模型 API key 应定期轮换。
