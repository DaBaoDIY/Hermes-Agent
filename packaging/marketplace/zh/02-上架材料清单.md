## 2. 需要你最终确认或补充的材料

| 材料 | 建议 | 说明 |
|:---|:---|:---|
| EULA | 准备 PDF 或公开 URL | AWS Marketplace 通常要求 EULA 或标准协议选择 |
| Support 联系方式 | 邮箱、工单地址、官网 URL | Listing 和客户支持需要 |
| 隐私政策 URL | 公司官网隐私政策 | 如产品涉及用户数据，建议提供 |
| 最终 Logo | 使用 VSTECS/Hermes 正式品牌资产 | 当前 Logo 是工作版 |
| 最终架构图 | 使用 AWS 官方 Architecture Icons 精修 | 当前架构图是工作版，可先用于测试 |
| 定价 | Free software | 客户支付 EC2/Bedrock 等 AWS 费用 |
| 产品可见性 | Limited -> Public | 先 Limited 测试，再申请 Public |
