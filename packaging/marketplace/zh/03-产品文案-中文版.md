# Hermes Agent Marketplace 产品文案（中文版参考）

本文档用于 Marketplace 控制台填写时参考。正式上架 AWS Global Marketplace 时，建议使用英文版文案；中文版可用于内部审批、销售沟通和中文客户资料。

---

## 产品名称

Hermes Agent on Rocky Linux

---

## 一句话简介

Hermes Agent 是部署在 Rocky Linux EC2 实例上的轻量级 AI Agent 控制台，支持通过 EC2 IAM Role 调用 Amazon Bedrock，并提供模型、MCP、Skills 与运行配置的可视化管理入口。

---

## 短描述

Hermes Agent 是一套面向云端 AI 运维与智能体应用的自托管控制台，以 AWS Marketplace AMI 形式交付，默认运行在 Rocky Linux EC2 上，并通过 IAM Role 安全调用 Amazon Bedrock。

---

## 长描述

Hermes Agent 帮助企业在自己的 AWS 账户中快速部署一个轻量级 AI Agent 控制台。产品提供 Web UI，用于配置 Amazon Bedrock 模型、外部 OpenAI-compatible 模型服务、MCP Server、Skills、系统提示词和推理参数。

默认部署使用 EC2 Instance Profile 调用 Amazon Bedrock，因此用户无需在 Web UI 中填写 AWS Access Key 或 Secret Key。每个实例首次启动时都会生成唯一 setup token，客户可以通过 AWS Systems Manager 安全获取 token，并进入控制台完成初始化。

Marketplace CloudFormation 交付模板会创建运行所需的 VPC、Subnet、Security Group、IAM Role、Instance Profile 和 EC2 实例。生产环境可进一步扩展 API Gateway、VPC Link、Internal Network Load Balancer、NAT Gateway、CloudWatch 和 Secrets Manager。

Hermes Agent 适用于需要在 AWS 上快速构建 AI Agent、模型调用桥接、MCP 能力中心、云端 AI 运维入口和 Bedrock 测试控制台的团队。

---

## 核心亮点

- 通过 EC2 IAM Role 调用 Amazon Bedrock，无需在应用中录入 AWS AK/SK。
- 支持 Amazon Bedrock Converse API。
- 支持 OpenAI-compatible、Anthropic API、Google Gemini API 等外部模型配置。
- 提供 MCP 与 Skills 能力中心。
- Web UI 使用 setup token 保护初始化入口。
- 支持 AWS Systems Manager 获取 setup token 和运维访问。
- 提供 Terraform 与 CloudFormation 交付模板。
- 预留 PRM 能力：Marketplace Metering、Resource Tagging、Bedrock User Agent String。

|:---|:---|
| 评估/测试 | `t3.small` |
| 小型团队 | `t3.medium` |
| 生产环境 | `t3.large` 或更高 |

---

## 默认安全模型

- Web UI 默认端口：`TCP 8080`。
- 安全组应限制到可信办公网、VPN 或堡垒机 CIDR。
- SSH 默认可不开放，优先使用 AWS Systems Manager Session Manager。
- Amazon Bedrock 权限通过 EC2 IAM Role 授予。
- setup token 每个实例首次启动生成，不应写入 AMI。
- 外部模型 API key 保存时会在 API 返回中脱敏显示。

## 典型使用场景

- Amazon Bedrock 模型快速测试与控制台化配置。
- 企业内部 AI Agent 原型部署。
- MCP Server 与 Skills 能力中心管理。
- 云端 AI 运维助手入口。
- 私有化部署的多模型调用桥接服务。

---

## 支持边界

支持内容：

- Marketplace 部署问题。
- CloudFormation Stack 创建问题。
- Hermes Agent 服务启动问题。
- Amazon Bedrock 连接与模型调用排查。
- setup token 获取与 Web UI 初始化。
- MCP/Skills 配置基础排查。

不支持内容：

- 客户自定义模型 API 的第三方服务可用性。
- 客户自行修改源码后的兼容性问题。
- 客户 AWS 账户中 Bedrock 模型访问审批。
- 客户业务提示词、业务数据和私有知识库质量调优。

---

## 支持请求需要提供的信息

- AWS Region。
- EC2 Instance ID。
- AMI ID。
- Hermes Agent 版本。
- CloudFormation Stack 名称。
- `sudo hermes-agent-ctl status` 输出。
- `sudo hermes-agent-ctl logs` 中与问题相关的片段。
- Bedrock model ID 或 inference profile ID。

请勿发送：

- AWS AK/SK。
- setup token。
- 外部模型 API key。
- 私有 prompt。
- 客户业务数据。
